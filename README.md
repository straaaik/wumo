# PixelThumbs

Wumo показывает миниатюры 3D-моделей и открывает быстрый просмотр в Проводнике Windows 10 и 11 x64.

## Установка

Скачайте `Wumo-…-Setup-x64.exe` со страницы [выпусков](https://github.com/straaaik/wumo/releases) и запустите его. Установщик работает без интернета и при необходимости запросит права администратора для установки комплектного .NET Desktop Runtime 10 x64. Откройте **Wumo** через меню «Пуск». Перед удалением закройте Wumo через меню трея, затем удалите его из списка установленных приложений Windows. Настройки и история буфера обмена остаются в профиле Windows.

## Подключение миниатюр

Откройте Wumo, выберите расширения или включите **«Все форматы»** и нажмите **«Применить»**. Из трея можно снова открыть окно или выйти из PixelThumbs. Поиск фильтрует список форматов по расширению и названию. Для запуска сборки в распакованной папке нужен .NET Desktop Runtime 10 x64.

При запуске обновлённой сборки она заменяет работающую предыдущую сборку с поддержкой обновления, а несохранённые настройки открываются как черновик. Повторный запуск через прежнюю версионную копию передаётся последней известной сборке. Путь уже включённого автозапуска обновляется при запуске новой сборки.

Проводник показывает миниатюры в режимах средних и крупных значков. Для отдельного файла в контекстном меню есть команда **«Обновить миниатюру PixelThumbs»**. В Windows 11 она может находиться в **«Показать дополнительные параметры»**. Двойной щелчок использует приложение, выбранное в Windows.

Для расширений можно использовать общий стиль или настроить собственный. Доступны цвет модели, фон, ракурс, наклон, освещение и отступы. **«Сбросить параметры вида»** возвращает исходные ракурс, наклон, освещение и отступы с сохранением цветов.

При изменении стиля **«Применить»** предлагает один раз очистить всю категорию **«Эскизы»** текущего пользователя через системный обработчик Windows. В эту категорию входят и эскизы фотографий и видео. После сброса Проводник создаёт эскизы по мере открытия папок. **«Сохранить без сброса»** сохраняет новый стиль. При ошибке очистку можно повторить из диалога. Изменения быстрого просмотра, автозапуска и списка расширений сохраняются обычным применением.

## Быстрый просмотр

Выделите один файл из списка поддерживаемых форматов в Проводнике или на рабочем столе и удерживайте **Пробел**. Если изображение модели недоступно, окно покажет свойства файла и причину. Пробел на файле вне списка оставляет окно закрытым. Отпустите клавишу, чтобы закрыть просмотр. При назначении другой кнопки наведите курсор на поддерживаемый файл. Пока Wumo определяет файл под курсором, кнопка действует как обычно. В разделе **«Настройки»** можно отключить быстрый просмотр, выбрать размер окна и назначить кнопку через **«Изменить»**. **Esc** отменяет назначение. Окно сохраняет фокус Проводника. В окнах на 768 и 1024 пикселя изображение масштабируется с 512 пикселей. PixelThumbs должен работать в трее. Автозапуск настраивается там же.

## История буфера обмена

Включите **«Историю буфера обмена»** в разделе **«Виджеты»** Wumo. Маленькая чёрная полоска у края экрана раскрывается при наведении. Сверху и снизу карточки ленты идут в ряд, по бокам — столбцом. Из трея панель можно открыть командой **«Открыть историю»**.

В настройках виджета выберите край и монитор. Полоса располагается по центру края и раскрывается в «Витрину» с анимацией «Пузырь». Кнопка **«Показать панель»** открывает витрину. Панель сворачивается при уходе курсора или по **Esc** при вводе в поиске. Слева доступны категории, по центру находится поиск, рядом с корзиной видно число записей в выбранной категории.

Перетаскивайте файлы, текст, ссылки и изображения на полоску или открытую панель. Щелчок по записи возвращает её в системный буфер для вставки через **Ctrl+V**. Для переноса удерживайте кнопку мыши и тяните запись в целевое окно. Меню **«Очистить»** поддерживает текущий список, недавние записи и всю историю.

Звезда закрепляет отдельную запись в **«Избранном»**. Корзина на карточке удаляет запись или, после подтверждения, папку со всем её содержимым. Перетащите одну карточку на другую в категории **«Все»**, чтобы создать папку. Щелчок по значку или свободной области карточки папки открывает её содержимое. Щёлкните по названию папки или сохранённой записи, чтобы изменить его на месте. **Enter** сохраняет название, **Esc** отменяет правку.

В обычной истории хранится до 30 записей суммарным объёмом до 64 МиБ. Автоудаление и шифрованное хранение обычной истории включаются в настройках виджета. Избранное и папки защищены от автоудаления и общей очистки истории. Они хранятся между запусками в зашифрованном виде. Для файлов, скопированных из Проводника, Wumo хранит пути к исходным файлам. [Результаты приёмки](docs/clipboard-acceptance.md)

## Форматы

- STL, OBJ, PLY, 3MF, GLB и самодостаточный glTF обрабатывает встроенный рендерер.
- STEP, STP, IGES, IGS и FBX обрабатывает комплектный F3D 4.0.1. После обновления PixelThumbs автоматически использует его для включённых форматов. [Выпуск F3D](https://github.com/f3d-app/f3d/releases/tag/v4.0.1)
- Fusion, SolidWorks, FreeCAD и G-code могут содержать готовое изображение. К нему применяются отступы и фон в прозрачных областях. `.f3d` здесь означает файл Autodesk Fusion.

## Сборка и отключение

Из корня проекта с установленным .NET 10 SDK. Подготовьте F3D один раз, если папка `vendor\f3d` ещё отсутствует.

```powershell
.\scripts\Install-BundledF3d.ps1
.\scripts\Publish-WumoUpdate.ps1
```

Скрипт подготовки F3D сверяет SHA-256 официального архива. В установку входят библиотеки и лицензии в `f3d`.

Для сборки установщика подготовьте F3D, установите [Inno Setup 7.1](https://jrsoftware.org/inno-setup/downloads) или более новую версию и передайте полный путь к `ISCC.exe`. Скрипт скачает и проверит комплектный .NET Desktop Runtime, затем создаст установщик в папке `dist`.

```powershell
.\scripts\Publish-WumoInstaller.ps1 -CompilerPath 'C:\путь\к\ISCC.exe'
```

Для следующего обновления снова выполните `./scripts/Publish-WumoUpdate.ps1`. После подтверждения запуска новой системной копии скрипт переключает миниатюры и автозапуск, затем удаляет старые системные сборки. Открыть актуальную версию можно через **Wumo** в меню «Пуск». Кнопка **«Обновить / перезапустить»** в верхней панели перезапускает установленную сборку. Несохранённые изменения настроек откроются как черновик.

Для изолированной проверки передайте скрипту параметр `-DataDirectory` с отдельным профилем. Скрипт подготовит обновление в папке этого профиля для проверки кнопки без изменения системной установки.

При применении с правами администратора PixelThumbs копирует пакет в защищённую папку `Program Files\PixelThumbs` и регистрирует системный COM-компонент. Стили, активные форматы и автозапуск хранятся в профиле пользователя.

Перед перемещением или удалением сборки закройте PixelThumbs в трее и запустите `PixelThumbs.exe --unregister`. Для системной регистрации запустите эту команду с правами администратора. Команда восстанавливает прежние обработчики текущего профиля и сохраняет общие записи COM, пока ими пользуются другие профили.

Проверки и ограничения прогона описаны в [отчёте](docs/acceptance.md).
